# WCG Radio

Интернет-радио в трее Windows.

- **Скачать:** [WCGRadio-setup.exe](https://lapizwcg.github.io/WCGRadio-Release/WCGRadio-setup.exe) — основная версия.
- **Для OBS:** [WCGRadio-OBS-setup.exe](https://lapizwcg.github.io/WCGRadio-Release/WCGRadio-OBS-setup.exe) — свёрнутое в трей
  радио остаётся видно в OBS («Захват звука приложения»). Ставится на место основной, станции и настройки сохраняются.
- **Ссылки на станции:** кнопка «Поделиться» в радио копирует ссылку вида
  `https://lapizwcg.github.io/WCGRadio-Release/?u=…&n=…`. Друг открывает её — запускается WCG Radio, станция добавляется в его
  список и сразу играет. Нет радио — страница предложит скачать установщик.

Здесь лежат только установщик и страница ссылок; исходники — в закрытом репозитории.
